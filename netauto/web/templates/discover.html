Discover hosts

ARP sweep of a directly attached segment. Hosts answer ARP even when they drop ICMP, so this finds more than a ping sweep — but only on networks this server is physically attached to. With check ports ticked, each host that answers is then dialled on the listed ports (SSH and telnet by default) to see which management paths are open. That is a plain TCP connect: it sends nothing and changes nothing.
