Topology

Reads each device's LLDP/CDP neighbour table and merges the reports into one graph. Every link is seen twice — once from each end — so a link both ends agree on is drawn solid, and one only a single device reported is drawn dashed. This opens a session per device, so it takes about as long as an audit.
